### Problema 1
**Sincronización de Sensores**

Descripción: Simula dos sensores que emiten valores periódicos:

- Sensor1: Rango [20°C, 30°C], cada 1 segundo.
- Sensor2: Rango [30°C, 40°C], cada 1.5 segundos.
- Usa zip para combinar los valores de ambos sensores en un solo flujo.
- Detén el flujo después de 10 pares de valores.
- Genera una alerta si la diferencia absoluta entre las lecturas de Sensor1 y Sensor2 es mayor a 5°C.
  

```mathematica
Sensor1: 22°C, Sensor2: 27°C, Difference: 5°C
Sensor1: 24°C, Sensor2: 34°C, Difference: 10°C
🚨 ALERT! Significant difference detected: 10°C
```
**Solucion:**
```scala
import rx.lang.scala.Observable
import scala.util.Random
import scala.concurrent.duration._

object SincronizacionSensores extends App{
  val sensor1 = Observable.interval(1.second)
    .map(_ => Random.between(20, 30))

  val sensor2 = Observable.interval(1500.millis)
    .map(_ => Random.between(30, 40))

  sensor1.zip(sensor2)
    .take(10)
    .subscribe(
      onNext = { case (temp1, temp2) =>
        val diff = math.abs(temp1 - temp2)
        println(s"Sensor1: ${temp1}°C, Sensor2: ${temp2}°C, Difference: ${diff}°C")

        if (diff > 5)
          println(s"🚨 ALERT! Significant difference detected: ${diff}°C")
      },
      onError = e => println(s"Error: ${e.getMessage}"),
      onCompleted = () => println("Stream completed!")
    )
  Thread.sleep(20000)
}
```
Explicacion
* Declaramos nuestros dos sensores ```sensor1``` y ```sensor2```, los establecemos como Observables los cuales en el intervalo de 1 segundo, se le asignara un numero aleatorio entre el 20 y 30, en el caso del sensor1, y entre el 30 y 40, en el caso del sensor2.
* Se realiza un zip entre el sensor1 y el sensor2; como nos pide el ejercicio usamos ```.take(10)``` para limitar el flujo a 10 valores. Por ultimo usamos ```suscribe```.
* A continuacion, usamos ```0nNext```, la cual tiene la funcion de recibir el siguiente elemento de una secuencia de datos asíncrona(Observable-Observer), lo que nos permite esta funcion es procesar eventos uno por uno. En la misma linea usamos el recibir ```case``` para condicionar temp1 y temp2.
* Declaramos la variable diff donde se almacena la resta entre temp1 y temp2, lo que necesitamos es el valor absoluto por lo que se usa ```math.abs```.
* Para presentar los datos usamos un print: ```println(s"Sensor1: ${temp1}°C, Sensor2: ${temp2}°C, Difference: ${diff}°C")```. En caso de que la temperatura presente un cambio de temperatura mayor a 5 se dispara la alerta: ```println(s"🚨 ALERT! Se ha detectado una diferencia significativa: ${diff}°C")```.

### Problema 2
**Sistema de Alerta Complejo**

Descripción: Simula tres sensores que emiten datos periódicos:

- Sensor1: Temperatura (20°C a 30°C).
- Sensor2: Humedad (40% a 60%).
- Sensor3: Presión (950 hPa a 1050 hPa).
- Combina los datos de los tres sensores y detecta si alguna de las métricas está fuera de rango.
- Detén el flujo después de 20 combinaciones.

```yaml
Temperature: 22°C, Humidity: 50%, Pressure: 970 hPa
Temperature: 25°C, Humidity: 42%, Pressure: 1055 hPa
🚨 ALERT! Pressure out of range: 1055 hPa
...
```
**Explicacion**
```scala
import rx.lang.scala.Observable
import scala.util.Random
import scala.concurrent.duration._

object SistemaAlerta extends App {
  val sensor1 = Observable.interval(1.second)
    .map(_ => Random.between(20, 30))

  val sensor2 = Observable.interval(1.second)
    .map(_ => Random.between(40, 60))

  val sensor3 = Observable.interval(1.second)
    .map(_ => Random.between(950, 1050))

  val combined = sensor1.zip(sensor2).zip(sensor3)
    .map { case ((t, h), p) => (t, h, p) }

  combined
    .take(20)
    .subscribe(
      onNext = {
        case (temp, hum, pres) =>
          println(s"Temperature: ${temp}°C, Humidity: ${hum}%, Pressure: ${pres} hPa")

          if (temp < 20 || temp > 30)
            println(s"🚨 ALERT! Temperature out of range: ${temp}°C")

          if (hum < 40 || hum > 60)
            println(s"🚨 ALERT! Humidity out of range: ${hum}%")

          if (pres < 950 || pres > 1050)
            println(s"🚨 ALERT! Pressure out of range: ${pres} hPa")
      },
      onError = e => println(s"Error: ${e.getMessage}"),
      onCompleted = () => println("Stream completed!")
    )

  // Mantener la app viva
  Thread.sleep(30000)
}
```
* Declaramos nuestros tres sensores: sensorTemp, sensorHum y sensorPres.
Cada uno se establece como un Observable que emite valores periódicamente; el sensor de temperatura emite cada 1 segundo valores aleatorios entre 20°C y 30°C, el de humedad cada 1.2 segundos valores entre 40% y 60%, y el de presión cada 1.5 segundos valores entre 950 y 1050 hPa.

* Para combinar los valores de los tres sensores utilizamos zip.
Dado que zip trabaja de a pares, primero realizamos un zip entre temperatura y humedad, y luego un segundo zip con el sensor de presión. Finalmente, mapeamos la salida para obtener una tupla con los tres valores.
Como el ejercicio lo indica, usamos .take(20) para limitar el flujo a 20 combinaciones y luego aplicamos subscribe.

* Dentro de onNext, recibimos el siguiente trío de datos emitidos por los sensores. Esta función procesa de forma secuencial los valores que recibe del flujo asíncrono (Observable–Observer). El uso de case (temp, hum, pres) nos permite separar cada lectura en variables independientes.

* A continuación, imprimimos los valores con
println(s"Temperature: ${temp}°C, Humidity: ${hum}%, Pressure: ${pres} hPa")
lo que nos permite visualizar el estado completo del sistema para cada emisión.

* Después realizamos las comprobaciones de rango para cada métrica:

* Si la temperatura está fuera de 20–30°C, se lanza una alerta.

* Si la humedad sale del rango 40–60%, también genera una alerta.

* Si la presión está fuera de 950–1050 hPa, se imprime la alerta correspondiente.

* Para cada caso fuera de rango, se usa un print como:
println(s"🚨 ALERT! Pressure out of range: ${pres} hPa")
de modo que el sistema indica inmediatamente cuándo una lectura representa un posible riesgo o anomalía.
